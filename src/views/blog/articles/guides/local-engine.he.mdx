כל לוח באפליקציה יכול לחפש עם Stockfish שרץ **ישירות במחשב שלכם** במקום בדפדפן: המנוע המלא, כל התהליכונים של המחשב, זיכרון Hash גדול יותר — מהירות גבוהה בכמה מונים מהגרסה שבדפדפן. האפליקציה מדברת איתו דרך **שרת מנוע** קטן שמגיע עם קוד המקור של האפליקציה ומאזין רק במחשב שלכם.

הבחירה בין השניים נעשית ב[הגדרות ← מנוע](/settings/engine): **דפדפן** לגרסאות שרצות בעמוד, **API** למנועים שבשרת שלכם.

## מה צריך

- **קוד המקור של האפליקציה**, עם התלויות שלו מותקנות — [github.com/pgntools/chess-trainer-app](https://github.com/pgntools/chess-trainer-app) (Node ו-Yarn).
- **Python 3.11 ומעלה** — השרת הוא שירות Python. ההפעלה הראשונה מתקינה את מה שהוא צריך לתיקייה משלו.
- **מנוע UCI** למערכת שלכם — כל מנוע שמדבר UCI מתאים; Stockfish הוא הנפוץ.

## 1. השיגו מנוע

הורידו את Stockfish מ-[stockfishchess.org](https://stockfishchess.org/download/) למערכת שלכם וחלצו אותו. רשמו את הנתיב לקובץ ההרצה — בלינוקס, למשל, `/home/you/stockfish/stockfish-ubuntu-x86-64-avxvnni`. שתי גרסאות זו לצד זו (Stockfish 18 ו-19) הן בסדר: השרת משרת כל מנוע שתרשמו.

## 2. ספרו לשרת היכן המנועים

בקוד המקור של האפליקציה, צרו את קובץ ההגדרות של השרת מתוך הדוגמה:

```sh
cp server/engine-api/engines.example.json server/engine-api/engines.local.json
```

אחר כך פתחו את `engines.local.json` ותנו לכל מנוע **מזהה** (`id`) ואת **הנתיב** (`path`) לקובץ ההרצה שלו:

```json
{
  "engines": [
    { "id": "stockfish-18", "path": "/path/to/stockfish-18" },
    { "id": "stockfish-19", "path": "/path/to/stockfish-19" }
  ]
}
```

**המזהה נזכר** — בבחירת המנוע שלכם ובכל משחק שתשחקו מולו — אז בחרו אחד ושמרו עליו. השם שהאפליקציה מציגה הוא שם המנוע עצמו (`Stockfish 19`), אלא אם תוסיפו `"name"`.

הקובץ נשאר במחשב שלכם: הוא אינו חלק מקוד המקור.

### הגדרות רשות

| מפתח | ברירת מחדל | מה הוא עושה |
| --- | --- | --- |
| `maxSessions` | 8 | מנועים שרצים בו־זמנית — אחד לכל לוח פתוח. |
| `idleTimeoutS` | 300 | מנוע שאף לוח לא השתמש בו זמן כזה נכבה. |
| `maxThreads` | מספר הליבות פחות 1 | מספר התהליכונים המרבי למנוע אחד. |
| `maxHashMb` | 4096 | זיכרון ה-Hash המרבי למנוע אחד, ב-MB. |
| `allowedOrigins` | — | אתרים מלבד המחשב שלכם שמותר להם להשתמש בשרת — ראו *שימוש מ-chessapp.dev* למטה. |

## 3. הפעילו את השרת

בחלון מסוף משלו, לצד האפליקציה:

```sh
yarn api:start
```

הוא מאזין בכתובת `http://127.0.0.1:8800` — במחשב שלכם בלבד (`ENGINE_API_PORT` משנה את הפורט). ההפעלה הראשונה יוצרת את סביבת ה-Python של השרת ומתקינה את מה שהוא צריך; ההפעלות הבאות לוקחות שנייה. השאירו אותו פועל בזמן העבודה באפליקציה, ועצרו אותו ב-Ctrl+C.

## 4. חברו אליו את האפליקציה

פתחו את [הגדרות ← מנוע](/settings/engine), ובלשונית **API**:

1. הפעילו את **שימוש בשרת מנוע**. כל עוד האפשרות כבויה, האפליקציה לא פונה לשרת כלל.
2. השאירו את הכתובת כפי שהיא (`http://127.0.0.1:8800`), אלא אם שיניתם את הפורט, ולחצו **התחברות**.
3. התווית שליד המתג אומרת **מחובר**, עם הזמן שלקח לשרת לענות; הכפתור מציג סימן וי בכל לחיצה.

המנועים של השרת מופיעים אז מתחתיו.

## 5. בחרו מנוע

בחרו אחד מהמנועים של השרת. הלוח שמימין מציג **מה הוא הצהיר** — אפשרויות ה-UCI שלו עם ברירות המחדל והטווחים, כפי שהשרת שלח אותן. מהחיפוש הבא, כל לוח משתמש בו: לוח הניתוח, סייר הפתיחות, משחקי הספרייה, הרפרטוארים ומשחק מול המנוע.

משחק שמתחילים מול המנוע משוחק במנוע הזה עד סופו, והמשחק זוכר איזה מנוע זה היה.

## איך זה מתנהג

- **מנוע אחד לכל לוח.** כל לוח מקבל מנוע משלו בשרת, שזוכר את מה שכבר חיפש בזמן שאתם עוברים על משחק — כך שהעמדה הבאה מושגת מהר יותר.
- **לא רץ שום דבר שאינכם משתמשים בו.** סגרו לוח, או בחרו גרסת דפדפן, והמנוע שלו בשרת נכבה. מנוע שנשאר מלשונית שנסגרה נכבה אחרי חמש דקות ללא שימוש (`idleTimeoutS`).
- **אם השרת נעצר**, הלוחות חוזרים לבד למנוע שבדפדפן, והבחירה שלכם חוזרת כשהשרת חוזר — לחצו **התחברות** כדי לבדוק.

## שימוש מ-chessapp.dev

השרת יכול לשרת גם את האתר המפורסם, עדיין מהמחשב שלכם:

1. הוסיפו את האתר ל-`engines.local.json` והפעילו את השרת מחדש:

   ```json
   "allowedOrigins": ["https://chessapp.dev"]
   ```

2. הפעילו את השרת ב[הגדרות ← מנוע](/settings/engine) ב-chessapp.dev, כמו למעלה.
3. ייתכן שהדפדפן ישאל אם לאפשר לאתר לגשת לאפליקציות ולשירותים אחרים במכשיר — אשרו. Chrome, ‏Edge ו-Firefox מאפשרים לאתר מאובטח לגשת למחשב שלכם; Safari עשוי שלא.

## פתרון בעיות

| מה רואים | מה לבדוק |
| --- | --- |
| **לא מחובר** — *אין חיבור אל …* | האם `yarn api:start` פועל, בכתובת שבשדה? באתר המפורסם: האם הוא ב-`allowedOrigins`, ואישרתם את שאלת הדפדפן? |
| *… ענה, אבל לא כשרת מנוע* | הכתובת מצביעה על משהו אחר — תוכנה אחרת בפורט הזה, או האפליקציה עצמה. |
| מנוע שרשמתם חסר | ה-`path` שלו שגוי או שאינו ניתן להרצה: המסוף של השרת אומר איזה מנוע לא הצליח להפעיל. |
| כל המנועים תפוסים | `maxSessions` מנועים מחפשים בו־זמנית — סגרו לוח, או הגדילו אותו. |
